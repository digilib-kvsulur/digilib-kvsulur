# Logo Placeholder Directory

Place your school logo image files here so they appear in the site header on all pages.

## Required Files

| Filename | Description | Recommended Size |
|----------|-------------|-----------------|
| `pm-shri.png` | PM SHRI National Programme logo | 64×64 px minimum, transparent background |
| `kv.png` | Kendriya Vidyalaya Sangathan / School crest | 64×64 px minimum, transparent background |

## Notes
- Use **PNG format** with a transparent background for best results
- If either file is missing, a fallback icon will be displayed automatically
- The images are displayed in overlapping circular frames (40×40 px) in the header navbar
- Supported formats: PNG, JPG, SVG, WEBP

## Where these appear
- Home page navbar (`/`)
- Catalog page navbar (`/catalog`)
- Login page left panel
- Footer (pm-shri.png only)
